# nextai-essays

散文集站点:https://nextai.show/essays/

四篇散文 + 关于页 + 音乐曲库(写字的时光)。

- `index.html` — 散文站单页(题图 SVG、抽屉导航、网易云风播放组件、曲库/搜索/排行)
- `music-api/` — TypeScript 音乐 API(网易云搜索/排行中转,页面 CORS 用)

音频文件(曲库 mp3)与封面图因版权不入库,部署时由脚本从网易云外链下载。

## 音乐曲库

- 曲库 21 首:本地 mp3(网易云外链下载,仅限独立音乐人可外链部分)
- 在线播放:扫码登录网易云账号(NeteaseCloudMusicApi),`/api/play` 返回 128k 流地址,搜索/排行任意歌可播
- 限流提示:在线播放走单一账号,低频个人使用 OK,公共高频会触发网易云风控
